<p>If you need to exchange a cable from a recently received order, you can exchange it free of charge if it's within the Hardware Warranty and meets return eligibility requirements.</p>
    <div class="callout note"><strong>Note</strong><p>The Cable Exchange Tool is available only to customers in the United States, Mexico, or Canada. Users need a Full Admin or Standard Admin role, a tag administrator role, or a custom role with permission to make purchases and submit warranty exchanges.</p></div>
    <h3>Identifying the cable</h3>
    <p>Locate the white lettering printed on the cable's shrink tubing — the printed cable code is required to complete an exchange request. For Vehicle Gateway (VG) cables, use the code to determine the cable class (B, C, or D). Verify carefully, since similar-looking codes can have different specifications.</p>
    <p>Examples: <strong>B-class</strong> CBL-VG-BIZU · <strong>C-class</strong> CBL-VG-CIZU · <strong>D-class</strong> CBL-VG-DIZU</p>
    <div class="callout important"><strong>Important</strong><p>These classes are not interchangeable.</p></div>
    <h3>Submit a cable exchange request (US, Canada, Mexico)</h3>
    <ol>
      <li>Identify the cable as described above.</li>
      <li>From the Samsara dashboard, select Help &amp; Feedback → Exchange Cable.</li>
      <li>Complete the form with the required cable and gateway details.</li>
      <li>To add multiple cable types, select "Add another cable type" and repeat.</li>
      <li>Click Continue, provide shipping information, and check the box confirming agreement with the warranty and RMA policy, then click Submit.</li>
    </ol>
    <p>You'll receive a confirmation email with a return label, followed by a separate email with tracking details once the replacement ships. Contact Support with any issues.</p>
    <h3>Outside the US, Mexico, and Canada</h3>
    <p>Cable exchanges are requested directly through Samsara. For <strong>new cables</strong>, contact your Account Executive. For <strong>replacement cables</strong>, submit a Support request including shipping contact info, the cable SKU being returned, and the VIN or asset identifier associated with the cable.</p>
